Как создавался сайт

WordScope — это результат практического подхода к изучению Django. Сайт построен на основе нескольких приложений:

  • popular_words — отображает часто используемые английские слова с фильтрацией по типу
  • analyzer — позволяет загружать текстовые файлы и анализировать частоту слов
  • core — содержит главную страницу и общую структуру
В процессе разработки использовались:
  • Django ORM для работы с базой данных
  • SQLite для хранения словаря
  • Ручные скрипты на Python для массовой загрузки слов
